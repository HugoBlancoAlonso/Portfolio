## 📌 Propósito de este repositorio

Este repositorio centraliza todos los proyectos prácticos y soluciones tecnológicas que he diseñado y desarrollado. El objetivo no es solo mostrar código, sino demostrar la capacidad de **resolver problemas reales de negocio** mediante la creación de arquitecturas sólidas, integraciones modernas (IA, Bases de Datos Vectoriales, APIs) y un código limpio, escalable y estructurado bajo los mejores estándares de la industria (Microservicios, Docker, etc.).

Cada carpeta de este repositorio representa un proyecto independiente y completamente funcional.

## 📂 Directorio de Proyectos

A continuación se detallan los proyectos actualmente disponibles en el portfolio:

### [📁 01 - Analizador Inteligente de Contratos](./01-AnalizadorContratos)
**Tecnologías:** `Python` `FastAPI` `Streamlit` `ChromaDB` `NLP` `Docker`

Una plataforma inteligente diseñada para automatizar la revisión de contratos de arrendamiento. Extrae el texto de archivos PDF, segmenta automáticamente el documento en cláusulas individuales y utiliza una **Base de Datos Vectorial (ChromaDB)** junto con Modelos de Lenguaje (Sentence Transformers) para detectar cláusulas abusivas o ilegales comparándolas con un diccionario legal preestablecido. 

👉 **[Ver detalles del proyecto](./01-AnalizadorContratos/README.md)**

---

### [📁 02 - Predicción de Generación Eléctrica](./02-PrediccionGeneraciónElectrica)
**Tecnologías:** `Python` `Jupyter` `Pandas` `Docker` `Dashboarding` `Machine Learning (En Desarrollo)`

Un pipeline de datos completo estructurado en arquitectura Medallón (Bronce, Plata, Oro). Este proyecto se encarga de la ingesta, limpieza, transformación y visualización de datos históricos de generación eléctrica y meteorológicos (AEMET, ESIOS). Incluye un panel interactivo y sentará las bases para un futuro modelo predictivo de Machine Learning de la demanda energética.

👉 **[Ver detalles del proyecto](./02-PrediccionGeneraciónElectrica/README.md)**
